# KC Earn: Your African Showcase

Build a real production-ready React application called KC Earn.



KC Earn is an African social content platform where users can share videos, discover creators, and later participate in a reward ecosystem.



For Stage 1, create the foundation only:

- Home feed screen

- Explore screen

- Upload screen

- Notifications screen

- Profile screen

- Bottom navigation

- Video content cards

- Categories: Funny, Music, Experience, Sports, Learning, Serious Topics



Create a clean modern mobile-first design.

Do not create fake earning systems or payment features yet.

This is the real foundation for future stages.
